# Project Title: Biped Character Animation in OpenGL

## AI Use
This project utilized **ChatGPT** for the following tasks:
- **Assisting with the design of the character's skeletal structure** and animation logic.
- **Providing guidance on OpenGL VAO/VBO setup** and proper GLSL uniform handling.
- **Explaining key concepts** such as camera movement, matrix transformations, and the integration of animation cycles.

**Note**: All code was written, tested, and verified by me. The AI was used for understanding, suggesting improvements, and offering explanations. Any code or concepts suggested were independently implemented and verified.

## Tools and Libraries Used:
- **GLFW** for window management and input handling.
- **GLAD** for loading OpenGL extensions.
- **GLM** for matrix and vector operations.
- **OpenGL** for rendering the 3D character and handling animations.

## Instructions:
1. Clone or download the repository.
2. Open the project in **Visual Studio 2022** or another C++ IDE.
3. Ensure that the necessary libraries (GLFW, GLAD, and GLM) are properly linked.
4. Build and run the project to see the biped animation.

## Controls:
- **W**: Move forward
- **S**: Move backward
- **A**: Rotate left
- **D**: Rotate right

## Key Features:
- Simple character animation using a skeletal system.
- First-person camera that follows the character.
- Real-time animation control based on keyboard input.
